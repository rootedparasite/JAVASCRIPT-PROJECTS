## Project 01 — Shopix Electronic Store

**Shopix** is a complete and fully responsive electronic store frontend built from scratch using **HTML5, CSS3, and Vanilla JavaScript**.

The project is designed to provide a realistic e-commerce experience with a modern interface, intuitive navigation, interactive functionality, and responsive layouts that adapt seamlessly across desktop, tablet, and mobile devices.

Shopix demonstrates how a complete e-commerce frontend can be developed using core web technologies without relying on frontend frameworks. The project focuses on clean UI design, structured code, responsive layouts, and JavaScript-powered interactions.

### Key Features

- Fully responsive e-commerce interface
- Modern and clean user interface
- Product browsing experience
- Product detail pages
- Interactive navigation
- Responsive product layouts
- JavaScript-powered functionality
- Mobile-friendly design
- Clean and organized frontend structure
- Cross-device responsive experience

### Technologies Used

- **HTML5** — Semantic structure and markup
- **CSS3** — Styling, responsive layouts, animations, and UI design
- **Vanilla JavaScript** — Interactivity, DOM manipulation, and frontend functionality

### Project Purpose

Shopix was created as a practical frontend project to demonstrate how **HTML, CSS, and Vanilla JavaScript** can be combined to build a complete, polished, and responsive e-commerce website from the ground up.
