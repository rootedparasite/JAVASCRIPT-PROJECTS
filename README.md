## Project 01 — Shopix Electronic Store

**Shopix** is a complete, fully responsive electronic store frontend built from scratch using **HTML5, CSS3, and Vanilla JavaScript**.

The project is designed to provide a realistic e-commerce experience with a modern interface, intuitive navigation, interactive elements, and responsive layouts that adapt seamlessly across **desktop, tablet, and mobile devices**.

Shopix demonstrates how a complete e-commerce frontend can be developed using core web technologies without relying on frontend frameworks. The project focuses on clean UI design, reusable structures, responsive layouts, and functional JavaScript-driven interactions.

### Key Features

- Fully responsive e-commerce interface
- Modern and clean UI design
- Product browsing and product detail experience
- Interactive navigation and UI elements
- Responsive product layouts
- Dynamic JavaScript functionality
- Mobile-friendly design
- Structured and maintainable frontend code
- Built entirely with HTML5, CSS3, and Vanilla JavaScript

### Technologies Used

- **HTML5** — Structure and semantic markup
- **CSS3** — Styling, responsive layouts, animations, and UI design
- **Vanilla JavaScript** — Interactivity, DOM manipulation, and functionality

### Project Purpose

Shopix was created as a practical frontend project to demonstrate how HTML, CSS, and JavaScript can be combined to build a complete, polished, and responsive e-commerce website from the ground up.
